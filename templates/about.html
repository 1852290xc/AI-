关于 {{ site_name }}

校园里的闲置，大多还能用，只是找不对人。我们把「发布」这一步的麻烦交给 AI，让转手变得像发一条动态。

7 项本地 AI 能力

  • 智能分类：关键词打分，自动归入 6 个品类并给出置信度
  • 智能定价：按成色折价，给出低/中/高三档区间
  • 文案生成：按品类套模板，一键生成描述
  • 内容审核：违规词库命中即拦截，说明原因
  • 标签提取：成色、型号、品类自动成标签
  • 个性化推荐：内容 50% + 偏好 35% + 热度 15%
  • 智能客服：常见问题即时答，答不了转人工

技术栈

  • Flask 3 + Flask-Login + Flask-SQLAlchemy
  • SQLite 单文件数据库，零安装
  • 原生 CSS/JS，Bootstrap 本地化，断网可用
  • AI 全部为纯 Python 规则引擎，无外部 API
